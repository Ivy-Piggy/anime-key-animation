# 按动作类型找场景（与 M-01–10 对应）

> 这是"收集连续动作"的**操作方法**：先把想要的动作**分类**，再去日本原画里按类型定向检索。
> ⚠️ 涉及具体原画师-镜头的归属，**引用前必须核验**（见下"核验流程"）。

---

## 一、分类检索表

| 动作库编号 | 动作 | 日本原画检索关键词（日/英） | 看什么 |
|-----------|------|------------------------------|--------|
| M-01 走 | 走 | 歩き / walk cycle | 重心起伏、脚落地形、上身的"稳" |
| M-02 跑 | 跑/追 | 走り / run / 疾走 | 腾空帧、收腿、抽帧位置 |
| M-03 转身回眸 | 转身、回头 | 振り向き / turn | 头身错拍、回眸后的静止长度 |
| M-04 跳落 | 跳、落 | ジャンプ / jump / 着地 | 滞空处理、落地压缩 |
| M-05 打斗 | 武戏 | アクション / effects / impact | 蓄势与抽帧的组合 |
| M-06 布料 | 衣纹、发、飘带 | 髪 / hair / 布 / cloth / なびき | 波的传导、延迟帧数 |
| M-07 道具 | 执物、掩面 | 小物 / 手 | 手的分组与滞后 |
| M-08 表情拍子 | 近景表演 | 芝居 / acting / 表情 | 反应延迟、微表情、静止的用法 |
| M-09 群戏 | 群像 | 群集 / crowd | 三层分工、错拍 |
| M-10 特效 | 烟、火、水、光 | エフェクト / effects / smoke / fire | 逐帧法、循环、骨架感 |

**额外高价值标签**：`impact_frames`（冲击帧）、`smear`（拖影/变形帧）、`debris`（碎片）、`smoke`、`hair`、`run`、`walk_cycle`。
> 注意：各站点标签体系不同，**以实际站点的自动补全为准**，别背标签名。

## 二、核验流程（每个条目都要走一遍）

```
① 在 sakugabooru 检索 → 拿到片段 + 标签
② 记录：作品名 / 集数或时间码 / 被标注的原画师（含"待定"状态）
③ 到 原画@wiki 或 BD 特典交叉核对原画表记
④ 若两处不一致 → 在条目里写"归属存疑"，不要写定论
⑤ 更新 ../references/sourcing-log.md
```

**为什么这么严**：原画归属是这个圈子里最容易出错、也最容易被专业读者挑出来的地方，比引用错文献还致命。**宁可写"某作品某段落"，不写"某人某镜头"。**

## 三、片段收集的操作步骤（可固定成流程）

| 步 | 操作 | 工具 |
|----|------|------|
| 1 | 找源（BD/流媒体/社群片段） | — |
| 2 | 切出 3–10 秒片段 | `ffmpeg -ss 00:12:30 -t 6 -i src.mp4 -c copy clip.mp4` |
| 3 | 逐格导出（可选，做逐格分析用） | `ffmpeg -i clip.mp4 -vf fps=24 frames/%04d.png` |
| 4 | 数关键姿势、写阶段拆解 | 见 [../03-motion/00-index.md](../03-motion/00-index.md) |
| 5 | 归类进 M-xx 条目 | — |
| 6 | 记核验状态 | [../references/sourcing-log.md](../references/sourcing-log.md) |

> 本机没有 ffmpeg（见"本机工具链"），可用 `cv2`（OpenCV）逐帧读取导出，或任意剪辑软件逐帧截图。

## 四、看片训练的三个层次（教学用）

| 层次 | 看什么 | 时长/次 |
|------|--------|---------|
| L1 感受 | 正常速度看，说出"哪里爽" | 1 分钟 |
| L2 结构 | 0.5 倍速 + 逐格，数关键姿势与打数 | 10 分钟 |
| L3 复原 | **不看原片**，凭记忆重画那 2 秒的关键姿势，再对照 | 30 分钟 |

**L3 是最有效的**：它把"看"变成"会"。建议作为每周固定作业。
