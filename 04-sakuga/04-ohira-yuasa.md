# 大平晋也 · 汤浅政明 —— 自由变形派

> 这一派的信念是：**只要"重量与惯性"是真的，形状可以随便变。**
> 对戏曲动画的价值：**服装与身体可以大幅设计化**（近于"图案"），但气流与重量仍然可信。
> ⚠️ 作品归属为通行说法；引用前请核验。

---

## 一、大平晋也（Shinya Ohira, b. 1966）

| 项 | 内容 |
|----|------|
| 身份 | 原画 |
| 代表 | 《御先祖様万々歳!》(1989)、《MIND GAME》(2004)、《恶童》(2006)、《乒乓》(2014) ⚠️ |
| 关键词 | 自由变形、"扭"的身体、极准的惯性、线的涂鸦感 |

**风格四条**：
1. **形状自由，物理准确**：人物可以像橡胶一样被拉拧，但**重心的抛物线、惯性的延迟**完全正确——这是"变形不假"的秘诀。
2. **线的暧昧**：轮廓线常常"糊"、"多"、互相穿插，反而增强了运动的连续感。
3. **身体的整体"扭"**：不是局部动，而是整个身体像一条被甩动的绳。
4. **速度与形变的耦合**：越快越变形，越慢越写实。

**戏曲用法**：不可整体照搬（会破坏"端庄"），但**可用于情绪爆发的瞬间**（如"惊梦"的一刹那），或**用于水袖/飘带**（布料本来就该自由变形）。

## 二、汤浅政明（Masaaki Yuasa, b. 1965）

| 项 | 内容 |
|----|------|
| 身份 | 原画 / 监督 |
| 代表 | 监督《MIND GAME》(2004)、《海马》(2008)、《四叠半神话大系》(2010)、《乒乓》(2014)、《恶魔人 crybaby》(2018)、《若能与你共乘海浪之上》(2019)、《犬王》(2022) |
| 关键词 | **舞台化**、图案化、非写实但高度设计、身体作为"形状"、自由的时间 |

**风格四条**：
1. **身体 = 形状**：极端简化或极端拉伸，把身体当"图案元素"用。
2. **舞台感**：动作、构图、配色都像舞台剧（**这一点与戏曲的"舞台性"高度共振**）。
3. **时间自由**：一段动作内可以突然从写实变为符号化（如"心象世界"）。
4. **动得"轻"**：形状自由到可以像剪纸/皮影一样运动。

**为什么对戏曲动画特别有价值**：
戏曲本身就是**反写实的舞台艺术**。汤浅证明了一件事：**动画完全可以不做"写实"，而做"设计"**——用颜色、形状、图案、舞台装置性的空间来表达。这条路比"好莱坞式真实"更接近戏曲的本性。

**可借**：舞台化的空间处理（前景遮挡、平面化构图）、身体作为形状、情绪的图形化表达。
**慎借**：幅度过大、节奏过快（会失去昆曲的"静"）。

## 三、变形派的使用纪律（给戏曲动画的三条）

| 规则 | 说明 |
|------|------|
| **只在"该变"的地方变** | 只有水袖、飘带、衣纹、头发可以自由变形；五官与手掌尽量守住形体 |
| **只在"该变"的时刻变** | 情绪爆发点、神话/梦境段落；日常段落保持写实 |
| **变形时物理要更准** | 变形越大，重心与惯性越要精确（否则会"飘"） |

## 四、检索关键词

`大平晋也` / `Shinya Ohira` / `汤浅政明` / `Masaaki Yuasa` / `Mind Game` / `作画 変形`

## 五、学习任务

1. **变形 vs 物理**：找一段大平晋也，写出"哪一帧形变最大"，同时验证重心是否合理。
2. **舞台化构图**：从汤浅作品里抄 5 张构图，问"它是舞台还是电影"。
3. **限域变形**：在同一段动作里，只允许水袖变形，身体守住写实，看效果。
