# 矶光雄 · 吉成曜 —— 机械与特效

> 一个把"机械与爆炸"画成精密仪器，一个把"火焰与烟"画成有骨架的装饰。
> 对戏曲动画：用于**仙气、云雾、光芒、火彩**的段落。
> ⚠️ 具体镜头归属与"イソカット""吉成爆炸"等称谓属社群共识，引用前核验。

---

## 一、矶光雄（Mitsuo Iso, b. 1966）

| 项 | 内容 |
|----|------|
| 身份 | 原画 / 监督 |
| 代表 | 原画《新世纪福音战士》(1995–)、《攻壳机动队》(1995) 等 ⚠️；监督《电脑线圈》(2007)、《颠倒的帕特玛》(2013) |
| 标志 | **イソカット**：把精密机械/爆炸用"三维辅助 + 二维精描"的方式处理，产生超越手绘上限的复杂运动 ⚠️ |
| 关键词 | 精密、层次、机械的"重量"、复杂度高的连续运动 |

**可学三条**：
1. **层次**：一个复杂运动拆成 3–5 层，各自速度（机械零件、碎片、尘埃、光）。
2. **精密的"慢"**：越复杂越要慢，让观众看清（与打斗的"快"相反）。
3. **三维与二维的混合**：能用 3D 辅助的部分就用，手绘用在"手感"上（现代 2D 制作的重要思路）。

## 二、吉成曜（Yo Yoshinari, b. 1971）

| 项 | 内容 |
|----|------|
| 身份 | 原画（特效） / 监督 |
| 代表 | 原画《FLCL》(2000)、《天元突破》(2007)、《Kill la Kill》(2013) 等 ⚠️；监督《小魔女学园》(2013 短片 → 2017 TV) |
| 标志 | **吉成爆発**：装饰性强、形状清晰、"有骨架"的爆炸与烟 ⚠️ |
| 关键词 | 特效的"造型化"、火的分离、烟的体积、装饰性 |

**可学四条**：
1. **形状清晰**：他的烟/火有明确的轮廓与"分层"，不是一团糊。
2. **装饰性**：特效可以是"好看的图案"（这点与戏曲的图案化审美相通）。
3. **逐帧法**：特效多用逐帧直推（不是先定关键帧）。
4. **与角色分离**：特效独立层、独立节奏，绝不与角色同步。

## 三、戏曲/神话段落的使用建议

| 段落 | 借用 | 避免 |
|------|------|------|
| 腾云驾雾 | 烟的体积感 + 长波飘带；写意化（线描云纹） | 日式爆炎、浓重黑烟 |
| 仙气/光芒 | 金田系光芒的"造型"用法 + 摄影的光晕 | 光污染、放射状爆闪 |
| 火彩/法阵 | 装饰性强、形状清晰的特效（吉成风） | 写实火焰 |
| 沉静段落 | 只用雨、水、烛火（押井守式） | 任何"热闹"的特效 |

## 四、检索关键词

`磯光雄` / `Mitsuo Iso` / `吉成曜` / `Yo Yoshinari` / `エフェクト作画` / `爆発 作画`

## 五、学习任务

1. **分层标注**：找一段爆炸，标出它由几层构成、每层的速度。
2. **逐帧推**：不给关键帧，直接逐帧画 24 帧的火，感受节奏。
3. **装饰化改造**：把一朵写实的爆炸云，改画成一朵"图案化"的云纹。
