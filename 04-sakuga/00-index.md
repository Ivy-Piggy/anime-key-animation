# 04 日本原画（Sakuga）· 模块导览

> 日本动画的"原画"（げんが）是一套**高度职业化、可辨识到人**的作画体系。对做 2D 动作与表演的人来说，它是全世界最好的"连续动作参照库"。

---

## 一、为什么日本原画值得专门学

| 理由 | 说明 |
|------|------|
| **可辨识到人** | 一集动画里有 10–20 位原画，各自的笔触、形变、轨迹都能被认出（欧美很难） |
| **有公共数据库** | sakugabooru 等社群数据库把镜头按**原画师**和**动作类型**打了标签 → 可检索、可分类 |
| **术语精细** | タメ/ツメ/抜き/クッション/缓急……对"节奏"的切分比欧美更细（见 [glossary.md](glossary.md)） |
| **限帧美学** | 用"少画"表达"更多"：静止、抽帧、留白 —— **与戏曲的含蓄天然合拍** |
| **量大可类比** | 同一动作（跑、回头、发飘）有几十个不同处理，便于做"对照学习" |

## 三、看日本原画的三条提醒

1. **"神作画"不等于"适合你"**。日本原画的最高成就多在**高速、剧烈、变形**的动作上；戏曲人物的近景与端庄动作，更适合学**井上俊之/冲浦启之的写实派**，而不是中村丰的打斗。
2. **区分"原画"与"演出"**：同一个镜头，"动得好看"归原画，"为什么这么安排"归演出/监督。学之前先想你要的是哪个。
3. **注意来源可靠性**：镜头归属靠社群考据，常有"无表记""第二原画""作监代笔"等情况。**引用前查 [sakugabooru](https://www.sakugabooru.com/) 与 原画@wiki**。本模块凡涉及"某人某镜头"处均标 ⚠️。

## 四、给戏曲动画的挑选建议（结论先行）

| 你要解决的问题 | 该看谁 | 为什么 |
|----------------|--------|--------|
| 近景微表情、眼神、呼吸 | **井上俊之 · 冲浦启之 · 今敏** | 写实派的近景表演最细 |
| 长静止 + 一次微动的"留白" | **押井守（演出）· 今敏（演出）** | "不动"的调度 |
| 衣纹、头发、飘带的连续波 | **井上俊之 · 大平晋也（变形时）** | 布料与头发的波传导 |
| 舞台化、图案化的身体 | **汤浅政明** | 非写实但**高度设计化**的身体 |
| 武打 | 中村丰 · 龟田祥伦 | 但幅度要**砍到 40%** 才适合戏曲 |
| 仙气、云雾、光芒 | 吉成曜系特效 · 金田光 | 用于神话段落 |
