# 日本原画术语表（附迪士尼对照）

> ✅ 术语本身为行业通用；⚠️ 标注处涉及具体作品/人，引用前请核验。

---

## 一、岗位与工序

| 日语 | 读法 | 中文/英语 | 干什么 |
|------|------|-----------|--------|
| 原画 | げんが / key animation | 原画 | 决定表演、姿势、时机、力的走向 |
| 第二原画 | だいにげんが | 第二原画 / 2nd key | 补足原画的次要部分（近年普遍化） |
| 動画 | どうが / inbetween | 中间画 | 补足帧，保持体积与线条 |
| 動画検査 | どうがけんさ | 动画检查 | 检查中间画 |
| 作画監督 | さくがかんとく / AD | 作监 | 统一造型；修正原画 |
| 総作画監督 | そうさくがかんとく | 总作监 | 跨集统一（近年的常见岗位） |
| 演出 | えんしゅつ | 演出 | 单集导演；决定镜头怎么"演" |
| 絵コンテ | えコンテ / storyboard | 分镜 | 镜头设计图 |
| レイアウト | layout | 构图 | 定镜头、空间、层关系（日本独有的强岗位） |
| タイムシート | time sheet | 摄影表 | 帧与时间的合同（见 [../01-principles/03-timing-spacing.md](../01-principles/03-timing-spacing.md)） |
| 兼用 | けんよう | 兼用卡 | 循环使用同一段作画（常规手法） |
| 背動 | はいどう / haidō | 背景动画 | 用背景移动表达镜头运动或人物位移 |
| ハーモニー | harmony | 特殊作画处理 | 停止/唯美镜头用的特殊上色（如回忆段） |
| 口パク | くちパク | 口型动画 | 只做口部（常为 3 形） |

## 二、节奏四术语（核心，务必记）

| 日语 | 含义 | 迪士尼对应 |
|------|------|-----------|
| **タメ** | 动之前的蓄势停顿 | anticipation 的"停留"部分 |
| **ツメ / 詰め** | 压缩间距使动作骤然加速 | — |
| **抜き** | 抽掉中间画 | 类似"极限抽帧"，无直接对应 |
| **緩急** | 快慢对比的整体设计 | 节奏曲线 |
| **クッション** | 缓冲 | Slow in/out |
| **中割り** | 中间画 | inbetween |

## 三、打数

| 日语 | 含义 |
|------|------|
| 一コマ打ち / 全コマ | 一拍一（24 张/秒） |
| 二コマ打ち | 一拍二（12 张/秒，**日本 TV 动画主流**） |
| 三コマ打ち | 一拍三（8 张/秒，省工/钝感） |
| 混用 | 同镜头内切换（制造节奏对比） |

## 四、社群/业界"风格名"（⚠️ 属非正式称谓）

| 名称 | 指什么 | 备注 |
|------|--------|------|
| 金田光 / 金田パース | 放射状光芒、极端透视、夸张轨迹 | 源自金田伊功的影响 ⚠️ |
| 板野马戏（板野サーカス） | 大量导弹/推进器齐射+缠绕飞行 | 源自板野一郎 ⚠️ |
| 大張ポーズ / 大張張り | 机械与人物的大开大合姿势 | 大张正己倾向 ⚠️ |
| イソカット（矶 Cut） | 精密机械/爆炸的 3D 辅助作画处理 | 矶光雄相关称谓 ⚠️ |
| 吉成爆発 | 装饰性强、骨架清晰的爆炸 | 吉成曜倾向 ⚠️ |
| 神作画 / 作画崩壊 | 社群对"极好/极差"作画的评价俗语 | 评价值得参考，不宜引用 |
| 作画 MAD | 粉丝剪辑的原画片段合集 | **入门最好的材料**（见 [08](08-scenes-by-action.md)） |
