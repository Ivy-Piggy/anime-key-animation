# 井上俊之 · 冲浦启之 —— 写实派（⭐ 最该学的一派）

> **如果戏曲动画只允许学一派日本原画，就学这一派。**
> 理由：写实派的强项正是**近景、微动、呼吸、衣纹、身体的重量**——恰好是你的短板与需求。
> ⚠️ 作品归属为通行说法；引用前请核验。

---

## 一、井上俊之（Toshiyuki Inoue, b. 1961）

| 项 | 内容 |
|----|------|
| 身份 | 原画（被称为「作画の神様」「原画の教科書」）⚠️ 称谓属社群 |
| 代表 | 《AKIRA》(1988)、《攻壳机动队》(1995)、《未麻的部屋》(1997)、《千年女优》(2001)、《恶童》(2006)、《在这世界的角落》(2016) ⚠️ |
| 关键词 | 写实、全身参与、重心、发与布的波、细腻的"微动" |

**风格五条**：
1. **重心第一**：任何姿势都先解决"重心在哪、支撑在哪"，所以动作"说服力"极强。
2. **发与布的自由**：日本原画中最精细的"波传导"之一（头发每一段都在动，且分先后）。
3. **微动**：静止镜头里的极小位移（肩、颈、呼吸）——**这正是近景表演的核心技术**。
4. **不做无意义的花招**：动作干净、无炫技，一切服务于"这个人此刻在做什么"。
5. **全身协调**：手脚、头、躯干没有"局部石化"。

## 二、冲浦启之（Hiroyuki Okiura, b. 1966）

| 项 | 内容 |
|----|------|
| 身份 | 原画 / 监督 |
| 代表 | 原画《AKIRA》(1988)、《攻壳机动队》(1995)、《老人Z》(1991) 等；监督《人狼 JIN-ROH》(1999)、《给桃子的信》(2012) ⚠️ |
| 关键词 | **写实作画的极致**、日常动作、儿童动作的"生理真实"、重量与惯性 |

**风格三条**：
1. **"实拍级"的动**：动作的节奏与间距接近真实人类，但**已经被设计过**（这点极重要：他不是描实拍）。
2. **儿童的动**：幼儿的坐、爬、抱、走——日本动画里对儿童身体最精确的观察者之一。
3. **少而准的姿势**：关键姿势少，间距准，所以动作"省"却"实"。

## 三、为什么这一派对戏曲动画有用

| 你的问题 | 写实派能给的答案 |
|----------|------------------|
| 近景木、没有戏 | 微动与呼吸的**技术参数**（不是"夸张"，而是"精确"） |
| 表演"表演痕迹重" | 写实派的口味：**越少越真** |
| 衣纹/头发不会动 | 波传导的分段与延迟帧数 |
| 身体没重量 | 重心—支撑—惯性的处理次序 |
| 甩不掉"迪士尼卡通味" | 写实派是"卡通味"的最佳解药 |

## 四、与戏曲的结合点

- **戏曲的"含蓄"与写实派的"微动"天然合拍**：都是"少做但做准"。
- **注意区别**：写实派追求"生理真实"，戏曲追求"程式的准确"。二者可以分工——**身体走程式（大拍），身体内部走写实（小拍）**，即 [../02-acting/06-opera-translation.md](../02-acting/06-opera-translation.md) 的双轨法。
- **谨慎点**：写实派的"日常感"可能削弱戏曲的"舞台感"。用它的**技术**，不要用它的**题材口吻**。

## 六、学习任务

1. **发丝逐段标注**：找一段头发飘动，逐格标出"哪一段先动"（写清帧号差）。
2. **重心反推**：取一张原画，反推重心垂线的落点。
3. **微动清单**：取一段 5 秒的静止近景，列出所有"在动的东西"及其周期。
