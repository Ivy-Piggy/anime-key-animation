# 口型与台词 / 唱腔节奏

> ✅ 通用做法层。**说话**和**唱**是两套完全不同的口型逻辑——戏曲动画最容易在这里翻车。

---

## 一、说话：口型表（够用版）

主流口型表 6–8 个形状。中文/日语用一个高度压缩的集合即可（日语所谓 **口パク**，常用「あ・い・う・え・お」五形；说唱段/台词多用 3 形省工版）。

| 形 | 对应 | 画法要点 |
|----|------|----------|
| A | 啊、啊韵开口（a/ɑ） | 下颌下落最多，舌位低 |
| I | 衣、西（i） | 嘴角横向拉开，下颌几乎不动 |
| U | 乌、呼（u） | 唇收圆向前，**嘴唇要"嘟"出来** |
| E | 诶（e） | 下颌中开，嘴角微拉 |
| O | 哦、喔（o） | 圆唇、下颌中开 |
| M/B/P | 闭唇 | 唯一需要"完全闭唇"的帧，**必须画准** |
| 齿唇（f/v） | 上齿咬下唇 | 半帧即可 |
| 中性 | 停顿、倾听 | 微闭、放松 |

**四条硬规矩**：
1. **口型不追每一个字**，追**重音与语气**。中文 4–5 字/秒，24fps 下塞不下每一个音素。
2. **闭唇帧最重要**（M/B/P）：它是观众判断"对不上口型"的最敏感点。
3. **口型帧要在表情之后做**：先定表情形状，再把口型"叠"在表情上，否则嘴会把脸上的表情抹平。
4. **呼吸与喉动要单独一层**：说话时下巴与喉结的运动比嘴早 1–2 帧。

## 二、日语原画的省工经验（能省 40% 帧数）

| 手法 | 做法 | 适用 |
|------|------|------|
| 3 形口型 | 只用 闭 / 半开 / 大 三形 | 中远景、快速对白 |
| 口型循环（口パク ループ） | 做 4–6 帧的口型循环反复用 | 长台词、背对镜头 |
| 侧脸口型 | 侧脸只做下颌开合 | 走路说话、群戏 |
| 台词留白 | 关键台词第一个字前留 2–4 帧静默 | 增强台词分量 |

> **注意**：这些是**省工手段**。近景大特写不要用——近景正是要"多画几张"的地方。

## 三、唱：唱腔的口型完全不同（戏曲动画必读）

昆曲/京剧的唱，**口型不是"说话的口型放慢版"**，而有自己的规矩（「字正腔圆」）：

| 特征 | 说话 | 唱（昆曲/京剧） |
|------|------|------------------|
| 基本单位 | 字 | **字 + 腔**（一个字可以拖很长） |
| 时长 | 单字 2–6 帧 | 单字可拖 24–96 帧（拖腔） |
| 口型幅度 | 随音素变化 | **小幅度、保持"腔口"形状**（口型自成一种稳定的形） |
| 变化方式 | 一个个音素切换 | **在一个持续形状上做微调**（波形式起伏） |
| 表情约束 | 表情可自由覆盖口型 | **唱时口型优先**，表情主要靠眼、眉、身段 |

**动画实现建议（重点）**：
1. 唱段用 **"腔口形状 + 微调"** 的方式，不要做逐字音素动画。
2. 唱段的**表演重心移到眼与身**——因为口型被"腔"占住了（这正是戏曲演员用"眼"演戏的原因）。
3. 唱段要有**换气帧**（明显的一口吸气 + 肩上抬 1–2 帧），这是"真唱"的信号。
4. **拖腔 = 天然的 hold**：拖腔期间不要加多余动作，让呼吸与眼神动即可。

## 四、口型 × 板眼：把节奏交给音乐

戏曲的时间骨架是**板眼**（曲牌的决定性节奏），不是物理时间。做法：

```
曲牌一拍（板）→ 摄影表上一个"格"
  ├─ 字头：口型到位（1–2 帧，一拍一）
  ├─ 腔腹：口型保持 + 微调（一拍二/三）
  └─ 腔尾：收口 + 换气准备
身段/眼神的高峰对齐到"板"上 → 动作天然合乐
```

**结论**：戏曲动画的摄影表应该**先画板眼，再填动作**。这样动作与音乐是一体的，而不是"先做动画后配乐"。详见 [../references/duliniang-project.md](../references/duliniang-project.md)。

## 五、课堂练习

1. **闭唇抓错**：给一段对白，只标注所有闭唇帧（M/B/P），检查动画有没有画准。
2. **3 形 vs 全形**：同一句台词做两版，比较省工与失真。
3. **拖腔练**：取昆曲一个 2 秒的拖腔，只用一个稳定的腔口形状 + 微调，加换气帧。
4. **板眼分格**：把一段唱分到摄影表格子上，先分板眼，再填动作。
