## 一、先给一句话诊断

近景表演"怎么努力都达不到要求"，按发生频率排：

| 排序 | 症状 | 真实原因 | 去哪个文件 |
|------|------|----------|------------|
| 1 | 表情只动嘴 | 表情靠**眼周**（眼轮匝肌）与**鼻唇沟**，不靠嘴 | [01](01-microexpression-facs.md) |
| 2 | 一听话就立刻反应 | 缺**反应延迟**（0.2–0.4 秒） | [02](02-closeup-acting.md) |
| 3 | 没有呼吸 | 静止帧里唯一证明"活着"的东西被省掉了 | [02](02-closeup-acting.md) |
| 4 | 眼睛不会演戏 | 眼球是高频省工部件，动画里必须**刻意加戏** | [03](03-eye-and-hands.md) |
| 5 | 所有部位同时起停 | 没有**错拍**（offset）：眼睛先、头后、手最后 | [02](02-closeup-acting.md) |
| 6 | 表情"符号化"到假 | 用程式符号填满了本该由生物性微表情填满的间隙 | [06](06-opera-translation.md) |

## 二、三层结构（本模块的统一框架）

```
层 3  表演设计层   这一段戏的意图 / 情绪曲线 / 板眼骨架     ← 导演讲的、原画要先想清
层 2  部件调度层   眼 / 眉 / 呼吸 / 头 / 手 / 嘴 的错拍表   ← 原画的日常工作，最见功力
层 1  肌肉与形状层 具体每一帧的肌肉状态与形变（FACS 层）     ← 微表情的"真"
```

**大部分"努力达不到要求"，是因为只在层 1 死磕（拼命画五官），而层 2 从来没有设计过。**

## 三、三十秒版行动清单（先照做，再读长文）

1. 写**错拍表**：一句话台词，标出 眼(0帧) → 眉(2帧) → 头(4帧) → 手(8帧) 的错拍。
2. 加**反应延迟**：听到信息后，第 4–8 帧才开始动。
3. 加**呼吸**：全程叠一层 24–36 帧的起伏，永不停止。
4. 拆**层**：眼睛/眉/呼吸/头/手/嘴 分六层，各自时钟。
5. 每个表情的"爆发帧"用**一拍一**，其余用**一拍二**。
6. 结尾给 2–4 帧 hold（收势），不要一到表情峰值就切镜头。
