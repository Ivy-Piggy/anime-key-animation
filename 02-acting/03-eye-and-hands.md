# 眼与手：四功五法与部件分工

> ✅ 戏曲侧为行业共识（「四功五法」是京剧/昆曲表演的基本框架）+ 动画侧为应用建议。

---

## 一、先接上戏曲的现成框架：四功五法

戏曲表演的「四功」与「五法」**天然就是一套"表演部件分工表"**，可以直接用来给动画表演分层——这比从零建立框架省事得多。

| 四功 | 内容 | 动画对应 |
|------|------|----------|
| 唱 | 唱腔 | 唱段口型与节奏（不是"说话"口型，见 [04-lipsync.md](04-lipsync.md)） |
| 念 | 念白 | 台词口型与停顿 |
| 做 | 身段表演 | **近景与中景的主体**：眼、手、身 |
| 打 | 武打/开打 | 动作戏原画 |

| 五法 | 内容 | 动画部件 |
|------|------|----------|
| **手** | 手势、指法 | 手/腕/袖的独立层 |
| **眼** | 眼神、眼法 | 眼球+眼皮+眉的独立层（**最贵的省工项**） |
| **身** | 身段、腰腿 | 张力线、体块倾斜 |
| **法** | 方法、程式规范 | 造型/风格统一（作监的活） |
| **步** | 台步、步法 | 走位与脚步原画、镜头调度 |

> **讲法建议**：先讲五法，学生立刻理解"手眼身法步 = 五个独立时钟"，再回到 [02-closeup-acting.md](02-closeup-acting.md) 的六条时钟，就通了。

## 二、眼：戏曲的"眼法"清单

戏曲有一套成体系的眼法，直接可转成动画帧设计：

| 眼法 | 做法 | 情绪 | 动画实现 |
|------|------|------|----------|
| 看 | 定睛直视 | 专注 | 眼球停住 + 眼皮不动（1 帧到位） |
| 睇 | 斜视 | 含情、打量 | 眼球斜移 2 帧 + 头不动 |
| 瞟 | 快速一扫 | 心虚、俏皮 | 2 帧内移开，**一拍一** |
| 瞄 | 偷看 | 羞、试探 | 眼皮半垂 + 眼球移 1–2 帧 |
| 瞪 | 睁圆 | 惊、怒 | AU5，2 帧到位，配 hold |
| 眯 | 收细 | 疑、笑、挑衅 | AU7，3–4 帧 |
| 含 | 眼皮微垂、不聚焦 | 怅惘、思念 | 长期半幅度 hold（杜丽娘主用） |
| 眼随手动 | 手指到哪，眼跟到哪 | 程式规范 | **手先 2 帧，眼后到**（错拍！） |

**四条动画侧的硬提醒**：

1. **动画里的眼睛是"省工区"**：因为它小、翻拍看不清，所以极易被简化 → 结果就是"没有戏"。**近景必须反过来，把眼当成最贵的部件去做。**
2. **眼要"先到"**：真人先看、后转头。动画里眼睛比头早 1–3 帧，观众就会觉得"这是活的"。
3. **眨眼是节拍器**：不是装饰。眨眼间隔 = 情绪强度的第二指标（紧张→频繁；心动→变慢）。
4. **瞳孔与泪膜**：大特写时，瞳孔的收缩、下眼睑的湿光（泪膜）是"含泪"的全部秘密，不要靠画水珠。

## 三、手：戏曲指法与"手不空"

| 要点 | 说明 |
|------|------|
| **兰花指 / 单指 / 剑指** | 造型符号；动画化时保留**手指的分组关系**（不要五根平行） |
| **手不空（手绝不空闲）** | 戏曲演员的手永远在动作中（理鬓、抚袖、执扇）。**近景里手没有"空白状态"** |
| **手是第二张脸** | 台词停顿时，手的微动代替说话（攥、抚、抖、按） |
| **手必须晚半拍** | 比意识慢 4–8 帧：先有念头 → 眼球动 → 头动 → **手才动** |
| **手的"收"比"出"重要** | 出手快、收手慢（且带一点回弹） |

**常见错误**：手在做"姿势"，而不是在做"事"。**手势要有目标物**（衣袖、鬓发、栏杆、扇子），否则是摆拍。

## 四、眼手配合的三种经典组合（可直接用于杜丽娘）

| 组合 | 帧表（一拍二，括号为帧） | 情绪 |
|------|--------------------------|------|
| **看物—伸手—收回** | 眼(0) → 手出(6) → 触(12) → 手停 4 帧 → 收回(24–36，慢) | 触碰回忆、试探 |
| **遮—露** | 手/袖遮(0–8) → 停 6 帧 → 露出眼(20–26，眼先出) | 羞、偷看 |
| **空望—垂手** | 眼望远(0–20) → 呼吸一次 → 手垂(30，慢慢落) → 头微低(40) | 怅惘（杜丽娘结尾常用） |

## 五、课堂练习

1. **眼法八张**：用同一张脸，画八种眼法（看睇瞟瞄瞪眯含眼随手），只改眼与眉。
2. **手不空**：一段 3 秒近景，禁止手处于静止打直状态，必须始终有"事"可做。
3. **错拍纸**：写下眼/头/手的帧号，要求三者必须不同帧起、不同帧停。
4. **大特写**：只画眼睛（含泪），不许出现眼泪珠，让同学猜情绪。
