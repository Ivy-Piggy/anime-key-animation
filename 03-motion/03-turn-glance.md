# M-03 转身与回眸

> 戏曲动画里最高频、最能出"戏"的一类动作。**回眸 = 一个转身的 20%，但承担 80% 的情绪。**

---

## ① 阶段拆解表

| 阶段 | 帧数 | 要点 |
|------|------|------|
| **预备（想转）** | 3–6 | 反向的肩膀/视线先行（欲右先左） |
| **头部先行** | 2–4 | **头比身体早 2–4 帧**（人先"看过去"，再"转过去"） |
| **肩—胸—盆依次旋** | 6–10 | 三块错拍旋转（错 2–3 帧）→ 这是"身体有体积"的关键 |
| **脚步调整** | 与旋转重叠 | 转身时脚要"换支撑"，画错会像陀螺 |
| **到位 hold** | 2–8 | 戏曲在此加"亮相"（6–12 帧） |

## ② 帧数配方

| 类型 | 总帧数 | 备注 |
|------|--------|------|
| 180° 转身 | 10–14 | 中间抽 1–2 帧更有力 |
| 360° 转身 | 16–24 | 需要 4–6 张关键姿势（正/侧/背/侧） |
| **回眸（头+少量肩）** | 6–10 | 头 4–6 帧到位，身体几乎不动 |
| **戏曲转身亮相** | 20–32 | 缓转 + 定型 + 长 hold |
| 甩袖转身 | 16–20 | 袖的路径比身体长，务必独立层 |

## ③ 关键姿势清单

180°：正 → 3/4 侧 → 侧 → 背 3/4 → 背（每张错拍）
回眸：正/低 → 眼先侧移（1 帧）→ 头转 60% → 头到位 + 下巴微抬/微收 → hold

## ④ 常见错误

| 错误 | 症状 |
|------|------|
| 头与身体同时转 | 像"整块纸板转" |
| 正面直接跳到背面 | 缺少中间透视，闪跳 |
| 旋转中心在脚上 | 人像一根杆子转 |
| 回眸时下巴角度不变 | 眼睛看不到"情绪"（下巴决定眼睛的可见量） |
| 转身时不换支撑脚 | 物理不通 |

## ⑤ 戏曲/民族风格调整

- **回眸是戏曲的核心语汇**（"回眸一笑"）：做法是**头先到、身缓随、眼先看**，然后**保持 6–12 帧**。切忌"快速回头再转走"。
- **下巴与眼神的关系**：戏曲回眸常"下巴微抬、眼从下方看上来"（含蓄）或"低头侧目"（羞）。**下巴角度就是情绪的开关**。
- **头面/步摇的跟随**：转头后，头饰晃 3–5 帧（独立层），这是"贵气"的来源。
- **水袖**：转身时袖的"离心甩开 + 收拢"是最好看的瞬间，独立分出 6–10 帧。

## ⑥ 参考方向（⚠️ 引用前核对）

| 方向 | 看什么 | 核验提示 |
|------|------|----------|
| 日式回眸 | 剧场版"回头"镜头的静止处理（常常半途定住） | ⚠️ 待核 |
| 美式转身 | 迪士尼转折身中的"肩领全身"与"裙摆离心" | 教材级可靠 |
| 戏曲回眸 | 舞台录像逐格看：眼→头→身→袖的顺序 | 剧目录像可靠（自己录最好） |

## ⑦ 课堂练习

1. **错拍表**：写出一段回眸的帧表，要求头/肩/胸/盆起止帧各不相同。
2. **下巴三档**：同一回眸，下巴微抬/水平/微收，三版对比情绪。
3. **头饰跟随**：只画头饰在回眸后的 5 帧晃动。
