# M-04 跳与落地

---

## ① 阶段拆解表

| 阶段 | 帧数 | 要点 |
|------|------|------|
| 预备（下蹲） | 4–8 | 欲上先下；手臂后甩 |
| 蹬地（离地） | 2 | **拉长变形**，帧数极少 = 爆发 |
| 上升 | 4–8 | 间距由大到小（减速）；手向上带 |
| **顶点滞空** | 2–6 hold | **必须有**，这是"跳起来了"的唯一证据 |
| 下落 | 4–6 | 间距由小到大（加速）；脚向前下探 |
| **触地压缩** | 1–2 | 压扁；重量的全部来源 |
| 缓冲回稳 | 6–10 | 2–3 次**递减**反弹后停 |

## ② 帧数配方

| 类型 | 总帧数 | 滞空 | 落地缓冲 |
|------|--------|------|----------|
| 轻巧跳（少女、飞鸟式） | 20–28 | 4–6 帧 | 2 次小反弹 |
| 普通跳 | 24–32 | 2–3 帧 | 2 次 |
| 沉重跳/落地（武将） | 28–36 | 1–2 帧 | 1 次大压缩 + 地面效果 |
| 跃起腾云（神话） | 32–48 | 8–16 帧 | 无触地压缩（缓降） |
| **戏曲"蹉步/跳步"** | 视板眼 | 短 | 上身稳、袖上扬 |

## ③ 关键姿势清单（6–8 张）

1. 预备最低 2. 蹬地拉长 3. 上升中 4. 顶点 5. 下落中 6. 触地压缩 7. 回弹 8. 站稳

## ④ 常见错误

| 错误 | 症状 |
|------|------|
| 无顶点滞空 | 像被弹射出去 |
| 无触地压缩 | 像纸片 |
| 缓冲一次到位 | 没有"肉" |
| 上升下落间距一样 | 像升降机 |
| 手臂与腿顺势不变 | 缺少"带"的动作 |
| 落地后立刻做下一个动作 | 缺"回稳"段 |

## ⑤ 戏曲/民族风格调整

- **神话式上升**：戏曲动画里的"腾云""驾雾"通常**不做触地压缩**，而做"缓升 + 衣带拖曳 + 人物定势"。下落用缓慢的"飘落"，衣裙先落到、身体后到。
- **戏曲起跳的准备常用"蹲身 + 甩袖"**（袖上扬代表升势），袖的上升滞后身体 3–4 帧。
- **落地**：戏曲人物的落地多为"轻如羽"，不强调压缩；重着陆改用"亮相 + 顿"（静止 4–6 帧）表达重量。

## ⑦ 课堂练习

1. **滞空长短**：同一跳做"2 帧滞空 / 8 帧滞空"，配重量词。
2. **缓冲递减**：画 1 次、2 次、3 次递减反弹，对比"肉的多少"。
3. **衣带先行**：只画落地时水袖/裙摆的 8 帧。
