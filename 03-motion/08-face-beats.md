# M-08 表情拍子：哭 / 笑 / 惊 / 羞 / 怒 / 忍 ⭐

> 表情**不是一张脸**，是**一串拍子**。每个情绪都有"结构性帧表"，背下来就能用。
> 每个条目给出：**触发 → 建立 → 峰值 → 余韵**四拍。帧数按 24fps 一拍二。

---

## 通用结构（所有表情都用这个骨架）

| 拍 | 帧数 | 内容 |
|----|------|------|
| ① 触发延迟 | 4–8 | 不动/只呼吸（听见了） |
| ② 建立 | 8–16 | 幅度上升；**建立快** |
| ③ 峰值 + hold | 2–12 | 峰值必须 hold（这是"戏"） |
| ④ 余韵/收回 | 16–40 | **收回慢**，且不完全回到起点 |
| ⑤ 微表情泄露 | 1–2 帧 | 插在②与④的**缝隙**里（见 [../02-acting/01-microexpression-facs.md](../02-acting/01-microexpression-facs.md)） |

---

## 一、哭（三种，区别巨大）

| 类型 | 特征 | 帧表要点 |
|------|------|----------|
| **含泪克制**（杜丽娘主用） | 眼不红、泪不下，只是**亮** | 眨眼变慢（间隔→5 秒）+ 下眼睑湿光 + AU17 下巴微收 + 一次深呼吸 + 视线游移 |
| **哽咽** | 喉动、肩动、吸气断 | 吸气 6–8 帧（断成 2 截）+ 肩抬 2–3 帧 + 咽下 1 帧 |
| **痛哭** | 面部扭曲、泪流 | 泪珠：拉长(2) → 脱离(1) → 坠落(3–5) → 拉丝；每滴错拍 3–5 帧 |

**泪珠画法**（最常做错的零件）：下眼睑积泪（1–2 帧鼓起）→ 汇成珠（2 帧）→ **被拉长成椭圆**后脱离 → 下落（间距递增）→ 拉出一条细丝留在脸上。

## 二、笑（四种）

| 类型 | 组合 | 要点 |
|------|------|------|
| 会心/浅笑 | AU12 单侧 + AU6 微 | 单侧！**对称的笑是面具** |
| 真笑 | AU12 + AU6 | 眼先 2–4 帧；眼睛被颊部顶起变细 |
| 假笑/客气 | AU12 单独 | 这正是"客气"的视觉定义，可**故意**用于礼节场面 |
| 大笑 | AU12 + AU6 + AU25 张口 | 用 2–3 次起伏（不是一条曲线），身体参与（肩、背） |

## 三、惊（两拍，绝不能只有一拍）

| 拍 | 内容 |
|----|------|
| 第 1 拍（惊） | AU1+2 + AU5 + 吸气半口 + **身体先僵**（0.2 秒） |
| 第 2 拍（回神） | 收回，只剩眉尾一点余韵；**收回比惊慢 3 倍** |

**错误**：只画"惊"不画"回神" → 变成一张定格表情，没有"活"。
**戏曲版**：惊常用"后退半步 + 袖微抬 + 眼瞪"（程式化），幅度比迪士尼小，但**hold 更长**（6–10 帧）。

## 四、羞（戏曲最核心的表情）

| 手法 | 说明 |
|------|------|
| **遮** | 袖/扇/帕遮面（见 [M-07](07-props.md)）→ 停 → 露眼 |
| 低头 | 头低 30–50%，**下巴微收**；眼从下方看上来 |
| 颊红 | **色指定层**的活儿：颊部淡红渐显 8–16 帧（不要突然出现） |
| 单侧嘴角 | 1–2 帧，幅度极小 |
| 呼吸变化 | 一次短促吸气 + 停 |
| 视线 | 先看 → 立刻避开（1–2 帧）→ 再看 → 再避（两次循环即"心动"） |

> **羞的技术难点**：它不是"一个动作"，而是**"看—避"的一组往复**。只做一次避视 = 呆；做两次 = 羞；做三次以上 = 撒娇。

## 五、怒 / 忍（戏曲人物的高频状态）

| 情绪 | 组合 | 幅度 |
|------|------|------|
| 怒 | AU4 + AU7 + AU17 + 身体前倾 | 戏曲版幅度 40–60%，配"甩袖/怒视" |
| **忍**（最有用） | AU4 半 + AU7 半 + AU15 + AU17 | 全部**半幅度 + 长时间 hold**（12–24 帧），靠呼吸与喉动维持 |
| 惊怒 | 惊的 1 帧 → 立刻转怒（2–4 帧内切换） | 转换速度决定"性格" |
| 悲愤 | AU1 + AU15 + 眨眼变慢 + 手攥 | 手是情绪出口（攥紧 2–4 帧） |

## 六、常见错误汇总

| 错误 | 症状 |
|------|------|
| 只有"建立"没有"收回" | 表情僵在半空 |
| 峰值不 hold | 表演被腰斩 |
| 对称 | 面具感 |
| 只动嘴 | 假 |
| 幅度 100% 用满 | 油；戏曲尤其忌 |
| 情绪切换在 1 帧内 | 抽搐 |
| 忘呼吸 | 死 |

## 七、课堂练习

1. **四拍骨架**：任意情绪都写成四拍表再画。
2. **羞的往复**：做"看—避"1 次 / 2 次 / 3 次三版，判断情绪差别。
3. **含泪不流泪**：只画眼睛，不许出现泪珠，让同学读情绪。
4. **忍的 hold**：24 帧里只有呼吸与一次喉动，其余保持。
