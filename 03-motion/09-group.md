# M-09 群戏与场面调度

> 群戏的原则：**主角永远只有一个"表演"，其他人是"运动"。**

---

## 一、三层分工

| 层 | 谁 | 画法 | 帧数 |
|----|----|------|------|
| **表演层** | 主角 | 完整表演（见 [M-08](08-face-beats.md)） | 一拍一/二 |
| **运动层** | 配角（2–4 人） | 有姿势、无表演；动作简化 30% | 一拍二/三 |
| **纹理层** | 背景人群 | 只做循环位移（走/摆/摇），可"兼用"（重复使用） | 一拍三，或循环 8–12 帧 |

> **"兼用"**（日语 兼用）：把一套群戏循环反复使用（如背景客流），是行业常规，不是偷懒。

## 二、调度五法

| 手法 | 说明 |
|------|------|
| **留白** | 主角周围留空，人群压缩到一侧 |
| **引导线** | 用人群的**朝向**指向主角 |
| **节奏反差** | 人群匀速动，主角有停顿（观众自动看主角） |
| **穿插遮挡** | 人/物从前景穿过（独立层，快速 3–5 帧），增加空间层次 |
| **焦点控制** | 只有主角有"面部细节"，其他人**不给五官细节** |

## 三、常见错误

| 错误 | 症状 |
|------|------|
| 所有人都"在演" | 观众不知道看谁 |
| 人群动作完全同步 | 像军训（应错开 3–8 帧） |
| 人群太齐整 | 缺乏生命感；应错落 |
| 群戏里主角没有停顿 | 被淹没 |
| 所有人同一速度 | 空间扁平 |

## 四、戏曲/民族风格调整

- **场面的"图案化"**：戏曲的群戏（龙套、宫女）常常组成**对称的图案**（一字排开、八字、双列）。**保留这种图案感**——它是戏曲美学的一部分，不要打散成自然主义的散点人群。
- **龙套的动作是"程式套路"**（站门、走边、排山），可以像"兼用"一样循环。
- **主角与群像的关系**：戏曲里主角"起霸""亮相"时，群像是**静止的衬托**（不动的众侍女、不动的兵卒）。这比"人人都在动"更有效。
- **配色纪律**：群像用低饱和，主角用高饱和（这条与全片色指定绑定）。

## 五、课堂练习

1. **三层练习**：同一镜做"全员表演/三层分工"两版对比。
2. **图案化**：把散点人群改成对称图案，看"戏曲感"是否出现。
3. **错开练习**：给 8 个人的同一个动作，全部错开不同帧起。
