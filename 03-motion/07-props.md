# M-07 道具：扇、袖、花、伞、帕

> 道具是"第二表演者"：它延长了角色的肢体，也替角色说话。

---

## 一、通用原则

| 原则 | 说明 |
|------|------|
| **道具跟随但不服从** | 道具的运动**滞后**于手，且有自己的"惯性轨迹" |
| **道具要有"重量等级"** | 扇（轻）/ 帕（极轻）/ 花（轻且有弹性）/ 伞（重且受风） |
| **道具是"目标物"** | 手永远在"对道具做一件事"（执、掩、转、掷、拈） |
| **道具独立成层** | 与手分层，才能做滞后与跟随 |
| **道具要"连戏"** | 上一镜在右手，下一镜不能在左手（连续性） |

## 二、条目录

| 道具 | 关键动作 | 帧数/要点 |
|------|----------|-----------|
| **折扇** | 开扇、合扇、掩面、指、掷 | 开扇 4–8 帧（甩开有"啪"的快）；扇面与手错拍 2–3 帧 |
| **团扇** | 掩面、半遮、轻摇 | 掩面 6–10 帧；团扇遮住脸的下半 → 表情靠眼（见 [../02-acting/03-eye-and-hands.md](../02-acting/03-eye-and-hands.md)） |
| **手帕/帕子** | 拈、抖、绞、甩 | 极轻，波动频率高；绞帕是"紧张"的强符号 |
| **花枝（梅花/牡丹）** | 拈、看、嗅、拈落 | 花枝有弹性：受力后**回弹 2–3 次**，幅度递减 |
| **伞** | 撑、收、转、挡雨 | 撑开 8–12 帧（有"弹"）；转动时伞面外缘走大圆弧 |
| **水袖** | 见 [M-06](06-cloth-hair-sleeve.md) | — |
| **酒杯/茶盏** | 执、举、饮、顿 | 液面要独立做晃动（滞后 3–5 帧） |
| **琴/书卷** | 抚、展、合 | 手指的"逐个到位"比整体动作更真实 |

## 三、常见错误

| 错误 | 症状 |
|------|------|
| 道具与手同时动停 | 像粘在手上的贴纸 |
| 道具无惯性 | 像没重量 |
| 道具抢焦点 | 观众看扇子不看脸 |
| 忽略连续性 | 手/道具左右颠倒、扇子忽开忽合 |
| 花枝不回弹 | 失去"弹性"（花最有戏的地方） |

## 四、戏曲/民族风格调整

- **扇子是戏曲的"第二张脸"**：扇褶、扇尖、扇骨构成的**几何形状**本身是构图元素。戏曲中"扇子功"是专门的功夫（开、合、翻、转、抛、接）。
- **以道具代表情**：戏曲常用道具遮挡（扇遮、袖遮）来表现"羞"，而**不做面部大表情**——这与迪士尼"让表情最大化"相反。用道具遮，反而更含蓄、更有戏。
- **团扇/扇子的"遮与露"**：遮住→停 6 帧→只露出眼睛（眼先出）＝ 一个完整的"羞"的表演。
- **道具的对称美**：戏曲身段常追求左右对称的造型（如双袖、双扇），但动画上仍要错开 1–2 帧避免僵硬。

## 五、参考方向（⚠️ 引用前核对）

| 方向 | 看什么 | 核验提示 |
|------|--------|----------|
| 美式 | 迪士尼道具跟随（扫帚、帽子、围巾） | 教材级可靠 |
| 日式 | 日常番中"执物"的手部描写（杯子、筷子、笔） | ⚠️ 待核 |
| 戏曲 | 扇子功/手绢功录像；京剧旦角"扇遮" | 自己录最可靠 |

## 六、课堂练习

1. **道具滞后表**：写出手与道具的帧表，要求错开 3–6 帧。
2. **遮与露**：用团扇做"羞"，只靠"遮—停—露眼"，禁止用面部表情。
3. **拈花**：花枝受力后做 3 次递减回弹。
