# M-02 跑与追逐

---

## ① 阶段拆解表

| 阶段 | 要点 |
|------|------|
| **蹬地**（接触） | 脚在重心**前方**落下，膝盖深屈缓冲 |
| **推离** | 蹬直，身体拉长，离地 |
| **腾空（Flight）** | **两脚同时离地** ← 跑与走的分界 |
| **摆动腿前摆** | 膝盖高抬、脚跟向臀收（收腿是速度感的来源） |

**跑的四个特征**：① 有腾空 ② 上身前倾 ③ 手臂大幅度折肘摆动 ④ 起伏与压缩都比走大。

## ② 帧数配方

| 类型 | 一步帧数 | 打数 | 备注 |
|------|----------|------|------|
| 慢跑 | 8 | 一拍二 | |
| 常速跑 | 6–8 | 一拍二 | 循环 12–16 帧 |
| 冲刺 | 4–6 | 一拍二 | 抽 1–2 帧更强 |
| **日式"暴走"跑** | 12–18 帧/循环 | **一拍三 + 抽帧** | 上半身前扑，轨迹夸张，落点集中 |
| 儿童跑/喜剧跑 | 6 | 一拍一 | 手脚夸张 |

## ③ 关键姿势清单（5 张/半步）

1. 蹬地（压缩）2. 推离（拉长）3. 腾空 A（最高、腿收）4. 前摆 5. 落地（最小压缩）
> 转身跑/跑入画时，用**3–5 帧的极短循环**重复 2–3 次即可表现高速。

## ④ 常见错误

| 错误 | 症状 |
|------|------|
| 没有腾空帧 | 看起来还是"走" |
| 腾空太长 | 像"月球漫步" |
| 上身不倾 | 缺少速度感 |
| 手没有折肘摆动 | 双臂像翅膀 |
| 抽帧抽错位置 | 抽掉了接触帧 → 脚"打滑" |
| 面部画满细节 | 高速时面部应简化（甚至只留剪影） |

## ⑤ 戏曲/民族风格调整

- **戏曲的"跑"**（如"碎步疾走""跪步"）与运动跑不同：**重心低、上身稳、脚下碎**。做"惊逃"时保留"水袖后扬"的跟随（袖向后飘，滞后 4–8 帧）。
- **飘带/披风**：奔跑是布料最出效果的场景——做成"顺流 + 反折"两种波形交替，别只画一条直线飘。
- **不要给戏曲人物做"冲刺式"低身位奔跑**，会破坏端庄；用"快步 + 急促呼吸 + 回头"表达慌乱。

## ⑦ 课堂练习

1. **腾空有无**：同一角色画两版（有腾空/无腾空），让同学判断哪个是跑。
2. **抽帧实验**：把 8 帧的跑循环抽成 6 帧、5 帧，比较速度感变化（注意别抽接触帧）。
3. **布料跟随**：只画水袖/披风在奔跑中的 8 张，不与身体同步。
