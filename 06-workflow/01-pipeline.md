# 从脚本到原画的工序

> ✅ 通用工序层。两种体系并列，因为**两种都要用**：迪士尼的长处是"表演设计的纪律"，日式 2D 的长处是"工程效率"。

---

## 一、两条工序对照

| 阶段 | 迪士尼/皮克斯（3D 与 2D 通用） | 日式 2D（TV/剧场） | 你的项目该怎么用 |
|------|-------------------------------|--------------------|------------------|
| 1 | 脚本 → **分镜/故事板**；反复"story reel"试映 | 脚本 → **絵コンテ**（分镜，含镜头时间） | 分镜里就要标**板眼**（戏曲项目特有） |
| 2 | 角色设定 + **表演设计**（beat 表：这场的情绪拍子） | **演出**给镜头方案；**レイアウト**定构图 | 抄"beat 表"这个动作，它最能救近景 |
| 3 | **录音先行**（先录台词，动画对口型） | アフレコ后配（TV）／プレスコ先行（剧场） | 戏曲项目：**唱段先行**，动画对板眼 |
| 4 | **实拍参考**（自己演，录下来） | 直接作画，少量参考 | 见 [../02-acting/05-acting-styles.md](../02-acting/05-acting-styles.md) |
| 5 | 粗原画（rough）→ 多次修 | **原画**（关键姿势 + 作画指示） | 你要做的是"粗原画"这一层的反复 |
| 6 | 关键帧（Tie-down）→ breakdown → 中间画 | **動画**（中割） | 中割之前，原画必须"成立" |
| 7 | 修改/作监级统一 | **作監**修正 | 自己一人作画也要有"作监环节"（隔天再校） |
| 8 | 上色/材质/灯光/合成 | 仕上げ（上色）→ 撮影（合成） | 摄影是"二次创作"的免费空间 |

---

## 二、迪士尼流程里最值得抄的三件事

| 抄什么 | 怎么做 | 为什么 |
|--------|--------|--------|
| **Story Reel（故事卷）** | 用分镜 + 临时配音 + 音乐剪成"会动的草稿"，反复看 | 在**动笔之前**发现节奏与表演的问题，成本几乎为零 |
| **Beat 表（表演拍子表）** | 一场戏拆成 5–15 个"拍子"（beat），每拍写一句"角色此刻想干什么" | 近景表演的"木"，多源于没有 beat 表 |
| **Daily / 试映** | 每周把粗稿放到大屏上放一遍 | 在屏幕上，"哪里不对"会自己跳出来 |

**Beat 表的写法（例子）**：

```
场：游园 · 见花
beat1 她走向花（想看清）
beat2 看清了花（心里一动）      ← 反应延迟在这里
beat3 想起自己（心里一沉）      ← 微表情泄露在这里
beat4 移开视线（不愿再想）      ← 视线先走、头后走
beat5 转身离去（脚步迟疑）      ← 结束时留一个未完成的动作
```

> **注意**：beat 表写的是"心里发生了什么"，不是"手怎么动"。这一层想清楚了，"怎么动"会自己出现。

## 三、2D 工序的三个效率要点（省工不省艺术）

| 要点 | 做法 |
|------|------|
| **兼用与循环** | 走路循环、转身、发飘，做一次用全片（行业常规，不是偷懒） |
| **分层** | 主体/附属物/前景/特效/背景分层（见 [../01-principles/06-drawing-order.md](../01-principles/06-drawing-order.md)） |
| **打数混用** | 长镜头里混用一拍一/二/三，把预算花在"关键帧的一拍一"上 |

---

## 四、戏曲项目特有的前置工序（建议加在最前面）

1. **板眼表先行**：把唱段/曲牌的板眼标成时间码 → 换算帧号 → 才写分镜。
2. **程式清单**：这场戏要用哪几个程式动作（只选 3–5 个），写成"动作词汇表"。
3. **双轨表**：每个镜头写两行（大拍/小拍），见 [../02-acting/06-opera-translation.md](../02-acting/06-opera-translation.md)。
4. **表演方针书**：见 [00-index.md](00-index.md)。

---

## 五、学习任务

1. **写一次 beat 表**：给你手上的一个镜头，写 5 个 beat，每个 beat 一句"她想干什么"。
2. **做一次 story reel**：用分镜 + 昆曲录音剪一个 20 秒的草稿，反复看三遍，记录"哪里别扭"。
3. **板眼换算**：把一段唱的高峰标成帧号，检查你现在的动作是否落在点上。
