# 动作拆解五步法（把一个动作变成可执行的"施工单"）

> ✅ 方法层。解决最磨人的那一句话：**"我知道这里要动，但不知道从哪一帧下手。"**
> 拆解的输出不是灵感，是一张**施工单** —— 填完就能开工，不用再想。
> 配套：[07-clinic 门诊表](../01-principles/07-clinic.md)（改错用）· [03 AI 流程](03-ai-video-pipeline.md)（哪一步交给 AI）

---

## 〇、总原则

**先写"发生什么"，再排"怎么动"。**

一句话意图句：**主语 + 动词 + 对象 + 为什么是此刻**。
写不出这句话，说明这个动作不该存在 —— 删掉它，比画它省一个月。

---

## 一、五步（每次拆解都按这个顺序）

| 步 | 做什么 | 产出 | 合格标准 |
|----|--------|------|----------|
| 1 | **写意图句**（一句） | 这一下"她要干什么" | 别人读一句话能说出动作方向 |
| 2 | **分三段 + 分配帧数** | 起势 / 动势 / 收势的帧数 | 三段都写了；收势没被省掉 |
| 3 | **数关键姿势**（3–6 张） | 每张一句话"这张负责什么信息" | 张数 ≤ 6；每张能过剪影测试 |
| 4 | **落摄影表** | 帧号 / 打数 / hold / 斜线（形变） | 标了"力的起点"与"谁最后停" |
| 5 | **自查三问** | 打钩 | 剪影 / 重心 / 末端 |

**第 2 步的帧数经验分配**（24fps）：

| 段 | 占比 | 特征 | 备注 |
|----|------|------|------|
| 起势（预备） | 15–25% | 反向、幅度 10–20%、时间要短 | 2–6 帧，过长会"慢" |
| 动势（主动作） | 40–50% | 帧最少、间距最大 → 最快 | 力的起点从这里发出 |
| 收势（缓冲/余波） | 30–40% | 缓冲 + 依次停 + 余波 | **收势占比越大越重、越柔** |

> 想让动作"重"：把比例往收势挪。想让它"脆、急"：把收势砍到最小 —— 但一刀不砍就变塑料。

## 二、施工单模板（复制即用）

```md
### 动作：____________（段号 S_ ／镜头 __）
- 意图句：
- 时长：__ 帧（24fps） 打数：一拍__
- 力的起点 → 末端：______ → ______（末端最后动、最后停）

| 段 | 帧号 | 关键姿势 | 这一张负责的信息 | 打数 |
|----|------|----------|------------------|------|
| 起势 |       |          | 反向蓄力（幅度 __%） |      |
| 动势 |       |          | 力的释放（间距最大） |      |
| 收势 |       |          | 缓冲 / 依次停 / 余波 __ 次 |      |

- hold：帧 __ – __（共 __ 帧）  斜线（形变）：__
- 自查：□ 剪影读得出  □ 重心在支撑面内  □ 末端最后停
- 交给 AI 的部分：______（只限材质/氛围）   自己画：______
```

## 三、常见动作拆解速查（24fps 经验值，按需调）

| 动作 | 起势 | 动势 | 收势 | 关键姿势 | 最易错 |
|------|------|------|------|----------|--------|
| 抬手 / 够物 | 2–4 | 4–6 | 4–8 | 4 | **指尖先动**（应髋→肩→肘→腕→指） |
| 回头 / 转身 | 3–6 | 5–8 | 6–12 | 5 | 头先动；应该**眼神先到、头后到** |
| 递物 / 接物 | 3–5 | 4–6 | 4–6 | 5 | 接触帧不共享 + 无回弹 → 像贴纸 |
| 坐下 / 起身 | 4–8 | 6–10 | 6–10 | 5 | 重心不转移（人像被抬起来的） |
| **被触碰（触觉反应）** | 1–2 | 3–5 | 8–16 | 4 | 反应无延迟；全身一起动（应局部先抖） |
| 落泪 / 情绪起 | 6–12 | 4–8 | 12–24 | 4 | 只动嘴、无眼周（AU6/AU12） |
| 持续用力（雕刻/推） | — | 循环 8–12/次 | 收势 6–10 | 6 | 只有手在动、躯干不动 → 假 |
| 转身离去（结尾） | 3–6 | 8–14 | 12–20 | 4 | **完全归位** → 没有"未完成感" |

## 四、把施工单接进一天（这一步才是"流程化"）

```
08:30  定段    读施工单，今天只推一段（一段＝一个"唯一目标"）
09:00  出姿势  只画关键姿势（3–6 张），禁止画中间画
14:00  落表    补间 + 摄影表（打数、hold、斜线）
16:30  回放    三层自查：缩到拇指大小 / 静音 / 只听声音
```

**一天只推一段。** 宁可 8 段 × 1 天，不要 1 段 × 8 天 —— 后者是"越改越乱"的唯一来源。

| 时段 | 做什么 | 不许做什么 |
|------|--------|-----------|
| 08:30–09:00 | 读施工单、定今天这一段 | 不许重画昨天那一段 |
| 09:00–12:00 | 关键姿势（3–6 张） | 不许抠线条、不许上色 |
| 14:00–16:00 | 补间 + 摄影表 | 不许临时改意图句 |
| 16:30–17:00 | 回放三层自查 + 记一行日志 | 不许"顺手再改一点" |

## 五、与 AI 流程的分界

| 施工单里的这一格 | 谁来做 |
|-----------------|--------|
| **关键姿势、收势、触觉、呼吸** | **自己画**（这些就是"选择"） |
| 材质、氛围、背景、尘屑、光 | 可以交给 AI（见 [03](03-ai-video-pipeline.md)） |
| 连续动作的中间画 | 自己补（AI 的连续动作仍不稳，别赌） |
