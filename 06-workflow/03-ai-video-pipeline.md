# AI 视频的确定性流程（流程卡 · 反"抽卡"）

> ✅ 实践层。**用途**：当你已经抽了一二十次还抽不到能用的镜头时，**别再抽** —— 照这张卡退回去，一次只改一个变量。
> **原理一句话**：抽卡是**让模型替你做选择**；流程卡是**把选择权拿回来**。抽卡不累积信息，流程才累积。

---

## 〇、先认清分工（这一步不认清，后面全是白费）

| 交给 AI（它擅长"像"） | 留给自己（它不擅长"选"） |
|----------------------|------------------------|
| 材质、光影、氛围、背景、粉笔/木屑/纸面质感 | **连续动作**（走、跑、落地、手脚） |
| 单镜情绪特写的**表面**（皮肤、绒毛、泪光） | **表演**（反应延迟几帧、眼比头早几帧、hold 多长） |
| 同一风格的大批量备选画面 | **多角色互动**、口型、接触与受力 |
| 你给的骨架的"重绘" | **哪一帧定稿**（选择永远由人做） |

> **判断法**：凡是被当成物理量去算的，AI 都会；凡是要取舍的，都还在人手里。

---

## 一、七步流程卡（照着走，不许跳步）

```
① 定"谁在动"     —— 主体动 / 镜头动 / 背景动，写死
② 上四锚         —— 角色参考图 + 风格串 + 种子 + 镜头参数（复制粘贴，禁止改写）
③ 声音先行       —— 先定音乐/唱腔/音效时间轴；按乐句或板眼划段边界
④ 划段（≤2 秒）  —— 每段写"这一段的唯一目标"（一段只做一件事）
⑤ 给骨架         —— 每段 3–5 张关键姿势草稿（或整段简笔/实拍）→ 运动来自你
⑥ 生成（一次一变量）—— 首帧 + 尾帧 +（骨架）+ 参考图；每轮只改一项，记日志
⑦ 缝合 + 验收    —— 尾帧接首帧 / 重叠 8–12 帧溶解；缩拇指看、静音看、只听声看
```

**②的四锚是命门。** 任何一项被"顺手改写"，前后两段立刻漂移，而你会误以为"AI 不稳定" —— 其实是锚变了。

| 锚 | 本片（《画中人》）的取值 | 漂移症状 |
|----|------------------------|----------|
| 角色参考图 | 杜丽娘 / 脆桃 / 小男孩 / 柳郎 各一张定稿三视图 | 脸型、头身比逐段变化 |
| 风格串 | 固定一串 8–15 词（粉笔灰 + 暖白纸感 + 陶土色），**全片不改** | 从粉笔感变成 smooth 3D |
| 种子 seed | 每段记下并尽量沿用 | 光向、色调乱跳 |
| 镜头参数 | 焦距感、运动方向、速度 | 一段推一段移，像两部片 |

## 二、抽卡日志模板（自己看的，也是你论文的实证材料）

每轮只填一行。**填不出"下一轮只改哪一项"，就不要开下一轮。**

| # | 日期 | 段号 | 目标（唯一） | 工具 | 输入（首帧/尾帧/骨架/参考图） | 参数（种子·时长·运动·风格串） | 结果 | **差在哪（只写 1 项）** | **下一轮只改哪一项** | 可用帧区间 |
|---|------|------|-------------|------|------------------------------|-------------------------------|------|----------------------|--------------------|-----------|
| 1 | | S3 | 脆桃"在减少" | | 首：… 尾：… 骨架：有 | seed 1234 / 2s / 缓推 / 串A | 体积没变 | 代价不可见 | 改成"桃身出现第一处缺口" | 12–26 |
| 2 | | | | | | | | | | |

**研究用加一列**：`与上一轮的相似度` —— 抽得越多越趋同，这就是"选择性密度"的实证。**你的抽卡记录本身就是数据。**

## 三、《画中人》分工表（哪段交给 AI、哪段必须自己画）

| 段落 | 交给 AI | 必须自己来 |
|------|--------|-----------|
| C1 仙女自陈 | 背景、光线、纸面质感 | 眼神与 4–8 帧反应延迟、呼吸 |
| C2 地面画柳郎 | 粉尘、地面材质 | **笔尖接触帧**、手腕的弧 |
| C3 说"不是" | **不要给** | 那 1 帧微表情泄露（幅度 40–60%） |
| C5 画在脆桃身上 | 桃身表面粉笔质感 | 载体转移的衔接 |
| C6 "摸不到，只能看"（主题句） | **不要给** | 手穿过画 / 触不到的空白 |
| C7 雕刻段（一镜到底） | 木屑、工具材质、环境光 | 接触与受力、**脆桃在减少**、第一次被触到 |
| C9 群像 | 群像氛围与动势 | 粉笔小人的**依次**加入（错开 2–4 帧） |
| C8 柳郎第一次呼吸（题眼） | **不要给** | 全片的立论点，交出去就变成均值 |
| C10 化月 | 月光、云雾 | 消解过程与最后的余波 |

## 四、四个最常见的坑

1. **整段生成**（一次出 30 秒）→ **必崩**。上限：单段 2 秒（48 帧／24fps）。
2. **一轮改多个变量** → 抽 100 次也学不到东西。**一次一变量**是不可让步的纪律。
3. **用形容词当控制** → "优雅地转身"是许愿不是指令。改用首帧/尾帧/骨架/参考图说话。
4. **没有日志** → 你会在第 20 次重复第 3 次的错误，还以为是工具不行。

---

## 五、什么时候该停手

同一段连续 5 轮都"差同一项" → **不是工具问题，是这一段的任务定义错了**。退回去改任务：

- "多角色互动" → 改成"多角色**依次**入画"（拆成单人镜）；
- "走过去" → 改成"**人不动、背景动**"（视差）；
- "复杂表演" → 改成"**一个微表情 + 一次呼吸**"。

> 推不动时，不是要更用力，是**要换更小的切口**。
