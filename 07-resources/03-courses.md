# 课程与自学路径（四周打卡清单）

> 设计原则：**每周只解决一个问题**，每天 1–2 个时段，可打勾。
> 时长按"有空的一天"设计；如当天没空，**把该格顺延，不要跳**。

## 自学资源方向（不指定具体课程，按类型找）

| 类型 | 怎么找 | 注意 |
|------|--------|------|
| 高校公开课 | 中国大学 MOOC 等平台搜"动画运动规律""原画设计" | 选有实物作业的 |
| 系统网课 | B站"原画/作画"类的完整系列 | 看讲师有没有真实作品 |
| 国外 | Animation Mentor 等（偏 3D）；YouTube 上的 2D 讲师 | 3D 的表演课对"表演"依然有效 |
| 戏曲身段 | 找昆曲/京剧身段教学视频，**逐格看** | 自己录老师示范最有用 |
| 软件 | Toon Boom Harmony / TVPaint / Krita / Clip Studio / Blender 2D ⚠️ 按需 | 工具不是瓶颈；本库不推荐软件 |
| 社群 | sakuga 社群、动画作画论坛 | 提问时给"帧号 + 具体问题" |

## 长期习惯（每周不变的三件事）

1. **一次 L3 复原**：不看原片，凭记忆重画 2 秒的关键姿势，再对照。
2. **一次逐格拆解**：任何一段好动作 → 写出阶段拆解 → 归入 [03-motion](../03-motion/00-index.md)。
3. **一次自查**：按 [06-workflow/02-self-check.md](../06-workflow/02-self-check.md) 走一遍。
