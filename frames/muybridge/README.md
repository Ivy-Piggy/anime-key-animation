# frames/muybridge/ · 动作连续图（实拍逐格）

> 来源：**Eadweard Muybridge《Animal Locomotion》(1887) 与《Animals in Motion》** —— 人类最早的动作连续摄影，
> 是"连续动作"这件事的**原始文献**，也是**公共领域（Public Domain / CC0 / CC BY）**，可自由用于教学与公开仓库。
> 检索与下载方式见 [Commons API 检索式](../../07-resources/02-databases.md)。
