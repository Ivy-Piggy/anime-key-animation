# 作画顺序与层结构（决定"能不能改"）

> ✅ 经验层。这一页不是美学问题，是**工程问题**：画的次序决定了你后面能不能改、中割好不好补、作监好不好修。

---

## 一、单张原画的落笔次序

```
① 构图框 / 视平线（先定镜头）
② 张力线（一条线定全身的力）
③ 头部位置与朝向（近景表演：先定眼的位置）
④ 胸腔—骨盆两块体块（倾斜方向相反 = 子午相）
⑤ 四肢的"端点"先定（手要放哪、脚踩在哪）
⑥ 关节与连接（不是描线，是"接上"）
⑦ 服装、水袖、头发的**附着点**（先定从哪长出来）
⑧ 五官（最后画，因为表情服务于①–⑦）
```

**为什么是这个次序**：改动的代价从下往上指数上升。①–③改一笔＝重画整张；⑧改一笔＝擦掉重画五官。所以**先把贵的定死**。

## 二、层结构（含 2D/3D 通用的分工）

| 层 | 内容 | 谁负责 | 备注 |
|----|------|--------|------|
| 背景 / 背动（BG） | 背景、背景动画 | 美术 | 背动 = 用背景移动表达镜头运动（日语 **背動 haidō**） |
| A 层 | 角色主体（身体） | 原画/中割 | 大多数镜头的主体层 |
| B 层 | 附属物（袖子、头发、道具、飘带） | 原画/中割 | **必须与 A 层分开**，否则无法做"跟随重叠" |
| C 层 | 前景遮挡（落叶、栏杆、帘子） | 美术/特效 | 增加空间层次与遮挡表演 |
| 特效层 | 烟、火、水、光、花瓣 | 特效原画 | 独立画法（见 [../03-motion/10-fx.md](../03-motion/10-fx.md)） |
| 摄影/合成 | 光效、色指定、虚焦、叠影 | 摄影 | 二次创作空间很大 |

**常见错误**：把水袖画进主体 A 层 → 主体一停袖子也只能停 → "布料感"永远做不出来。**水袖必须独立成层**。

## 三、原画指示（作画指示）该写什么

一段好原画，纸上除了画，还要有这些注记（中割看得懂才是好原画）：

1. **打数**（一拍二/三、哪几张是 hold）
2. **形变方向**（A→B 是"旋"还是"移"，画箭头）
3. **边界**（哪部分是"要跟"的：袖、发、裙）
4. **意图词**（"眼神先到""先停再动"）
5. **摄影提示**（需要什么光、是否叠影、是否要模糊）

## 四、近景表演的层分工（杜丽娘这类戏的关键）

一个 3–5 秒的近景，建议至少拆成：

| 层/部件 | 独立运动 | 不与主体同步的理由 |
|---------|----------|--------------------|
| 眼睛（瞳孔/眼皮） | 独立 | 视线比头更快到；眨眼节奏与情绪绑定 |
| 眉毛 | 半独立 | 眉眼不同时动（先眉后眼 = 思考；先眼后眉 = 情感冲击） |
| 呼吸（胸腹） | 独立循环 | 静止镜头里唯一的"活着"的证据 |
| 头/发饰 | 跟随 | 头动完，步摇/簪饰才晃 |
| 手/袖 | 跟随 | 手的动作比意识慢半拍更真实 |
| 嘴唇 | 独立 | 口型与呼吸、与眼神是三条不同时钟 |

> **近景表演做不好的根因，往往是把这六件东西当成一件在动。** 详见 [../02-acting/02-closeup-acting.md](../02-acting/02-closeup-acting.md)。

## 五、课堂练习

1. **次序实验**：故意先画五官再画身体，与按正确次序画，记录各自重画次数。
2. **分层拆解**：找一段好近景，逐层写下"如果我是原画，我会拆成几层"。
3. **作画指示练习**：把自己的作业交给同学当"中割"，看对方能否按你的注记补出正确中间画。
