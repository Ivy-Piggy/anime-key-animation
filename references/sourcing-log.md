## 五、核验方法速查

```
1. sakugabooru  → 片段 + 原画师标注（含 confidence）
2. 原画@wiki     → 逐集原画表记
3. BD 特典/原画集 → 最可靠
4. 两处一致 → ✅ ；否则 → ⚠️ 存疑（写"归属存疑"）
5. 中文图书     → 豆瓣/读秀/图书馆核对版本与页码
6. 中文论文     → CNKI 核对篇名/作者/年卷期页
```

> **原则**：不确定就写"存疑"。这个领域里，"说得太肯定"比"说得不确定"更致命。
