02 表演原画 · 模块导览

这个模块是为"戏曲人物近景表演"这个具体问题建的。

结论先说：近景表演做不出来，通常不是画技问题，而是"把六条不同的时钟当成了一条"。

文件内容解决什么
01-microexpression-facs.md微表情：FACS 动作单元 → 原画帧"表情不像、不真"
02-closeup-acting.md近景表演清单（六条时钟 + 三秒结构）"近景很木、没有戏"
03-eye-and-hands.md眼与手：四功五法与部件分工"眼神没有表情、手不知道放哪"
04-lipsync.md口型与台词/唱腔节奏"说话/唱腔对不上、嘴在乱动"
05-acting-styles.md三大表演体系对照 + 实拍参考法"不知道自己该学哪一派"
06-opera-translation.md戏曲程式 × 迪士尼法则：冲突与转译（核心章）"套迪士尼就串味"

一、先给一句话诊断

近景表演"怎么努力都达不到要求"，按发生频率排：

排序症状真实原因去哪个文件
1表情只动嘴表情靠眼周（眼轮匝肌）与鼻唇沟，不靠嘴01
2一听话就立刻反应缺反应延迟（0.2–0.4 秒）02
3没有呼吸静止帧里唯一证明"活着"的东西被省掉了02
4眼睛不会演戏眼球是高频省工部件，动画里必须刻意加戏03
5所有部位同时起停没有错拍（offset）：眼睛先、头后、手最后02
6表情"符号化"到假用程式符号填满了本该由生物性微表情填满的间隙06

二、三层结构（本模块的统一框架）

层 3  表演设计层   这一段戏的意图 / 情绪曲线 / 板眼骨架     ← 导演讲的、原画要先想清
层 2  部件调度层   眼 / 眉 / 呼吸 / 头 / 手 / 嘴 的错拍表   ← 原画的日常工作，最见功力
层 1  肌肉与形状层 具体每一帧的肌肉状态与形变（FACS 层）     ← 微表情的"真"

大部分"努力达不到要求"，是因为只在层 1 死磕（拼命画五官），而层 2 从来没有设计过。

三、三十秒版行动清单（先照做，再读长文）

  1. 写错拍表：一句话台词，标出 眼(0帧) → 眉(2帧) → 头(4帧) → 手(8帧) 的错拍。
  2. 加反应延迟：听到信息后，第 4–8 帧才开始动。
  3. 加呼吸：全程叠一层 24–36 帧的起伏，永不停止。
  4. 拆层：眼睛/眉/呼吸/头/手/嘴 分六层，各自时钟。
  5. 每个表情的"爆发帧"用一拍一，其余用一拍二。
  6. 结尾给 2–4 帧 hold（收势），不要一到表情峰值就切镜头。
