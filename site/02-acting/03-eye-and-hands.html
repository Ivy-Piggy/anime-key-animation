一、先接上戏曲的现成框架：四功五法

二、眼：戏曲的"眼法"清单

戏曲有一套成体系的眼法，直接可转成动画帧设计：

眼法做法情绪动画实现
看定睛直视专注眼球停住 + 眼皮不动（1 帧到位）
睇斜视含情、打量眼球斜移 2 帧 + 头不动
瞟快速一扫心虚、俏皮2 帧内移开，一拍一

眯收细疑、笑、挑衅AU7，3–4 帧
含眼皮微垂、不聚焦怅惘、思念长期半幅度 hold（杜丽娘主用）
眼随手动手指到哪，眼跟到哪程式规范手先 2 帧，眼后到（错拍！）

四条动画侧的硬提醒：

  1. 动画里的眼睛是"省工区"：因为它小、翻拍看不清，所以极易被简化 → 结果就是"没有戏"。近景必须反过来，把眼当成最贵的部件去做。
  2. 眼要"先到"：真人先看、后转头。动画里眼睛比头早 1–3 帧，观众就会觉得"这是活的"。
  3. 眨眼是节拍器：不是装饰。眨眼间隔 = 情绪强度的第二指标（紧张→频繁；心动→变慢）。
  4. 瞳孔与泪膜：大特写时，瞳孔的收缩、下眼睑的湿光（泪膜）是"含泪"的全部秘密，不要靠画水珠。

三、手：戏曲指法与"手不空"

要点说明
兰花指 / 单指 / 剑指造型符号；动画化时保留手指的分组关系（不要五根平行）
手不空（手绝不空闲）戏曲演员的手永远在动作中（理鬓、抚袖、执扇）。近景里手没有"空白状态"
手是第二张脸台词停顿时，手的微动代替说话（攥、抚、抖、按）
手必须晚半拍比意识慢 4–8 帧：先有念头 → 眼球动 → 头动 → 手才动
手的"收"比"出"重要出手快、收手慢（且带一点回弹）

常见错误：手在做"姿势"，而不是在做"事"。手势要有目标物（衣袖、鬓发、栏杆、扇子），否则是摆拍。

四、眼手配合的三种经典组合（可直接用于杜丽娘）

组合帧表（一拍二，括号为帧）情绪
看物—伸手—收回眼(0) → 手出(6) → 触(12) → 手停 4 帧 → 收回(24–36，慢)触碰回忆、试探
遮—露手/袖遮(0–8) → 停 6 帧 → 露出眼(20–26，眼先出)羞、偷看
空望—垂手眼望远(0–20) → 呼吸一次 → 手垂(30，慢慢落) → 头微低(40)怅惘（杜丽娘结尾常用）

五、课堂练习

  1. 眼法八张：用同一张脸，画八种眼法（看睇瞟瞄瞪眯含眼随手），只改眼与眉。
  2. 手不空：一段 3 秒近景，禁止手处于静止打直状态，必须始终有"事"可做。
  3. 错拍纸：写下眼/头/手的帧号，要求三者必须不同帧起、不同帧停。
  4. 大特写：只画眼睛（含泪），不许出现眼泪珠，让同学猜情绪。
