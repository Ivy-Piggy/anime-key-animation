03 连续动作分类库 · 总表与入口

这个模块是"动作字典"。 每个条目一条动作，编号 M-xx，统一格式，可随时扩充。

目标：遇到任何动作，都能在这里找到 阶段拆解 + 帧数配方 + 关键姿势清单 + 常见错误。

一、条目编号体系

编号条目文件子类

⭐ = 戏曲动画最高频、最该先做的三条。

二、每条的统一格式

① 一句话定义
② 阶段拆解表（阶段 / 帧数 / 要点）
③ 关键姿势清单（该画哪几张原画，怎么数）
④ 常见错误
⑤ 戏曲 / 民族风格调整
⑥ 参考片例（⚠️ 镜头归属需核对，见各条的核验提示）
⑦ 课堂练习

开工前先出"施工单"：每条动作按 ../06-workflow/05-motion-breakdown.md 填一张（意图句 / 三段帧数 / 关键姿势 / 摄影表 / 自查），填完再动笔 —— 这是"流程化做动画"的起点。

三、怎么用（30 秒决策）

  1. 先判断动作类型：位移？力？布料？表演？
  2. 进对应条目，照"阶段拆解表"排帧。
  3. 数关键姿势：一段动作的"关键姿势"通常 3–6 个，超过 8 个说明你没在做取舍。
  4. 用摄影表落定（见 ../01-principles/03-timing-spacing.md）。
  5. 自查：剪影测试（../01-principles/05-silhouette-line.md）+ 六条时钟（../02-acting/02-closeup-acting.md）。

四、收集方法学：怎么"积累连续动作"（给持续扩充用）

你要的"收集连续动作并分类"，建议按这个流程固定下来：

步做什么产出
1找到片段（B站/YouTube/蓝光；sakugabooru 按标签检索）视频片段 + 时间码
2逐格导出（ffmpeg/剪辑软件逐帧）帧序列图（另存到本项目 frames/ 或本地）
3数关键姿势，写阶段拆解一条 M-xx 条目的"阶段表"
4反推帧数（数帧 / 看打数）帧数配方（可补充到 ../01-principles/04-frame-recipes.md）
5归类进 M-xx，补"戏曲调整"与"课堂练习"更新条目
6记核验状态（⚠️ 引用前查 sakugabooru）更新 ../references/sourcing-log.md

不要只存视频。存视频是"收藏"，写出阶段拆解才是"资料"——前者会烂在硬盘里，后者能进课堂、进论文。
