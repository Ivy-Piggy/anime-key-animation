动漫原画设计 · Key Animation Design

一个给动画创作者用的原画设计资料库：动作规律、动作节奏、连续动作分类、日本原画（sakuga）经典、中国戏曲动画传统。

起点问题：戏曲人物（杜丽娘）的微表情与近景表演做不到位 —— 学的是迪士尼/皮克斯风格，但原画原理没打底。

这个库解决什么

症状缺的东西对应模块
动作"能动，但不好看、不干净"动作规律（力、预备、跟随、弧线）01 原画原理
动作"有，但没有力"（轻飘飘／像机器人／说动就动／一停就死）蓄力·惯性·重量感·弧线四个工位的可操作旋钮01 原画门诊
动作"节奏是平的，没有轻重缓急"时间与间距、摄影表、缓急控制01 原画原理
近景表情"不真、木、没有戏"表演原画：微表情、眼神、呼吸、口型02 表演原画
想做某个具体动作（走/转身/水袖）没参照连续动作分类库03 动作库
想让动作更有"日本动画那种爽感"日本原画师与经典连续动作04 日本原画
民族风格动画不知道怎么"化"中国动画原画传统（美影厂、戏曲动画）05 中国原画
不知道从脚本到原画的工序迪士尼/皮克斯工作法与自检表06 工作法
用 AI 却推不动（抽卡抽不到、一镜到底拼不上）确定性流程：四锚 · ≤2 秒分段 · 三种缝法 · 抽卡日志06 工作法
知道要动，但不知道从哪一帧下手动作拆解五步法（意图句 → 三段 → 关键姿势 → 摄影表 → 自查）06 工作法
不知道去哪找、看什么书书单、数据库、检索式07 资源

项目档案：杜丽娘案例推演 · 《画中人》脆桃短片 · 检索与核验记录

三种用法

  1. 备课 —— 03 动作库 每条都有「课堂讲法」栏：一个动作规律 → 三个正反例 → 一个课堂练习。
  2. 做片子查表 —— 遇到具体动作，从 03 的入口表直接跳到对应条目，拿帧数配方和间距注记。
  3. 写论文/申报素材 —— 04 与 05 有「术语对照」与「可引用判断」，可直接作为动画本体研究的材料。

核验约定（重要）

本库内容分三级标注，请按级别采信：

标记含义用法
✅原理性内容，行业共识，可放心使用直接用于教学与制作
⚠️具体作品-原画师-镜头的归属靠社群考据（sakugabooru 等），可能变动引用前先在 sakugabooru 用英文名 + 作品名查一次
🔎待补条目（已列大纲，尚未写满）欢迎按大纲继续扩充

动画原画圈的镜头归属考据是出了名的易错：同一镜头常有"作监代笔""第二原画""无表记"等情况。凡涉及"某某的哪个镜头"，务必查 sakugabooru 或 sakuga@wiki 再引用。
