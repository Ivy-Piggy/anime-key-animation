眼睛转场（推镜入瞳 · 虹膜匹配剪辑）

✅ 实践层。「推镜到眼睛 → 瞳内景象展开成下一场」是最古老的转场之一，专业叫 虹膜匹配剪辑（iris match cut）。

它比溶解高级的地方在于：遮罩是物理的 —— 瞳孔本身就是画面里唯一"天然的圆"，观众感觉不到"剪辑"，只感觉到"看进去"。

配套：04-one-take（四锚 / 三约束 / 缝法）· 03-ai-video-pipeline（分段与一次一变量）

一、三段结构（配四锚用；一段一运动）

段时长内容镜头（只做一种运动）谁来做
A 推近2 s（48 帧）人物在画面里不动，只有镜头缓推只推AI 可（背景/光/材质）
B 入瞳1–2 s瞳孔逐步占满画面 → 瞳孔边缘溢出画框推到底后几乎静止自己画
C 瞳内展开2 s上一帧的"瞳内景象"放大成新场景展开/反向混合

三张必须自己画的关键帧：

  1. 眼睛入画（眼睛成为画面的主体）
  2. 瞳孔中心（观众此时还没意识到要转场）
  3. 铰链帧：瞳孔边缘越过画框的那一帧 ← 整个转场的成败就在这一张

二、匹配剪辑的三条对齐（不对齐就会出现"顿"）

对齐项规则不对齐的后果
运动方向推入的方向 = 新场景展开的方向（同向继续，别反向）观众会感觉"被拉回去"
亮度曲线暗接暗、亮接亮；要反差就插 1–2 帧闪黑/闪白，别硬接硬接＝跳一下，转场感暴露
速度推入的末速 = 新场景的初速；末速为 0（停住）= 断掉顿挫，像卡了一帧

三、缝合参数（圆形遮罩）

  • 取 B 段最后一帧的瞳孔圆（中心 cx, cy，半径 r）为遮罩起点，逐帧放大到覆盖全画，3–5 帧完成；
  • 边缘羽化 2–4 px（硬边像老式过场，不"物理"）；
  • 瞳孔若偏离画面中心，遮罩中心要跟着眼位走（跟着头眼关系，不要固定死中心）。

四、三个奇幻画面：要"递进"，不要"并列"

排列原则：三画面 = 三级台阶，直接呼应本片主题（可看 → 不可触 → 可触）：

台阶介质可触性视觉关键
①纸 / 粉笔世界只能看线在生长、草图、未完成的留白
②水 / 墨世界有映象、摸不到映象破碎、倒影与实体错位
③陶土 / 木世界可触有实体、有缺口（预备"代价"）

三条硬规矩：

  1. 每画面 一个动作 + 一个运动方向，≤2 秒；
  2. 三画面共用同一风格锚 + 同一光向（否则像三个不同短片的素材拼起来）；
  3. "奇幻"来自 尺度错位（极大/极小）与 材质错位（水做成固体、纸做成布），不是元素堆叠（越多元素越均值）。
  4. 三画面之间用 同向运动匹配衔接（不要用溶解 —— 溶解会泄气）。

四·补、"神明视角"怎么实现（巨物 / 超现实）

先定一条：神明视角是视点，不是内容。同样的牡丹，俯拍是"看花"，仰拍溢出画框才是"被花看着"。

4.1 三条实现路径（可单用可叠用）

路径怎么做观众的感受
仰视巨物视点压到最低，主体占画面 2/3 以上并溢出画框我变小了
俯视无碍视点抬高：没有前景、没有遮挡、地平线移出画面我变大了 / 我在外面
无人视点画面里没有人、没有影子、没有视线指引我就是那个"看"

神明视角三条禁令：

  1. 不出现"人眼高度"的水平线（那是人的视角）；
  2. 不出现视点动机（不给人物视线引导，镜头无动机地看）；
  3. 不出现尺度参照物 —— 或用材质细节暗示尺度（指纹的旋纹、纸纤维、笔触的粗细）。

4.2 巨物化的三条做法（超现实不靠堆元素）

做法说明本片用法
尺度错位把熟悉的东西放到不属于它的尺度一根粉笔线 ＝ 横贯的山脉
材质错位换材质不换形状（水做成固体、纸做成布）牡丹花瓣做成陶土
语境错位把程式符号放进自然景观的位置翎子 ＝ 林；水袖 ＝ 云

4.3 戏曲元素的巨物化对照（这是本片作者性所在）

戏曲元素巨物化落在哪一台阶
鸟类（不要画真鸟）翎子（雉鸡翎）放大成森林／立柱；水袖翻飞 ＝ 群鸟起飞① 纸（线还没闭合）
蝴蝶蝶翼 ＝ 殿宇大门；翅上花纹 ＝ 地图② 水（倒影里的蝶比实体大 → 摸不到）
牡丹花枝花枝 ＝ 柱廊；花瓣 ＝ 台阶；花蕊 ＝ 光源③ 陶土（有实体、有缺口 → 可触）

关键判断：戏曲的"鸟"本来就在行头里（翎子），"翅膀"本来就在水袖里 —— 不必画真鸟。

把行头放大成自然景观，比"做一只巨型神鸟"更作者、更省、"AI 味"更低。

建议分配（三台阶各领一个元素）：① 翎子 → ② 蝴蝶 → ③ 牡丹。

4.4 提示词结构（给豆包／海螺／LibTV 用）

[视角] + [巨物对象与材质] + [尺度暗示] + [单一运动] + [光向] + [禁止项]

例：极低角度仰视，一根未闭合的白色粉笔线如山脉横贯画面，可见纸纤维，线条缓慢向前生长，侧逆光，无粒子、无星云、无发光边缘、无漂浮岛

4.5 禁用清单（这些一出现就变"AI 味"）

发光粒子 · 紫色星云 · 漂浮岛 · 对称神殿 · 光晕边缘 · 万花筒渐变 · 无意义镜头光斑 · 大量对称排布的小元素 · "史诗感"橙青对撞调色

替换思路：把"光效"换成"材质" —— 想发光 → 改成半透明的花瓣；想要粒子 → 改成粉笔灰的碎屑。

4.6 分工（很重要）

这一段正该交给 AI —— 巨物／超现实不需要连续动作、不需要表演，恰好落在 AI 的强项区。 所以本片的总分配是：奇观给 AI，表演给自己。

五、男主角登场：不要全身亮相

做法为什么
局部先到：先衣角 / 手指 / 半张脸在光里呼应主题"摸得到才算生命" —— 第一次接触先给"可触"的部分
影子先于实体先"看得见"，再"摸得到"，正好是主题的第二个台阶
从陶土/木的裂纹里"长"出来与"雕刻=生命"互文：他不是走来的，是被造出来的
正面给他的第一帧：1 帧吸气起手接题眼（C8 的呼吸）；这一帧绝不给 AI

六、AI 执行段表（接 03 的七步）

段秒目标（唯一）缝合方式谁来做
S0 推近2.0人物不动，只推镜尾帧接首帧AI（背景/光）
S1 入瞳1.5瞳孔占满 → 边缘溢出铰链帧 + iris 遮罩自己画
S2 奇幻①纸2.0线在生长同向运动匹配AI（材质）
S3 奇幻②水2.0映象破碎同向运动匹配AI（材质）
S4 奇幻③陶土2.0缺口出现同向运动匹配AI（材质）+ 自己补缺口
S5 柳梦梅2.0局部先到 → 正脸影 → 实混合；呼吸帧自己画

合计 ≈ 11.5 秒。

⚠️ 最大的坑：极近景眼球交给 AI = 塑料球 / 死眼。S1 的瞳孔段不要交给 AI ——

它是"生命"的隐喻，也是最容易被均值化毁掉的一格。

七、验收（转场专用）

  1. 静音看：转场"顺"不顺？（不顺 = 速度/方向没对齐）
  2. 只看接缝：铰链帧在不在？瞳孔边缘是否真的越过了画框？
  3. 主题检查：三个奇幻画面是否构成"可看 → 不可触 → 可触"的台阶？
  4. 缩到拇指大小：转场后观众能不能立刻说出"现在在哪一层世界"？
